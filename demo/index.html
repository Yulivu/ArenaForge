Quantum Optics 是第一个 Reference Arena，用来展示系统在开放科学问题上的完整运行。ArenaForge 围绕探索活动组织协议、执行和证据交付。

问题 → 协议候选 → 证据结论有边界
01 · 输入
科学问题研究者想知道什么，为什么值得探索。
02 · 固定
探索协议观察、行动、反馈、预算和成功标准。
03 · 探索
Agent 候选提出相互竞争的假设并执行分支。
04 · 记录
证据链代码、命令、结果、失败和反证不丢失。
05 · 输出
可审查结论支持、反驳、未决与复现包。
Product surface

用户获得一场完整探索及其可审查结论。

同一个协议下比较候选方案，才能知道改进是否真实、失败是否有信息，以及结论能覆盖到哪里。

A / QUESTION

把问题变成协议

声明研究目标、可运行环境、反馈信号、资源预算和不可修改边界。

B / CAMPAIGN

让 Agent 持续探索

候选方案进入隔离分支，按同一条件执行；通过和失败都进入研究记录。

C / DECISION

把证据交给研究者

输出 evidence graph、hash-chained ledger、problem certificate 和 replay bundle。
