# ArenaForge GOAI 初赛作品摘要骨架

## 作品名称

ArenaForge：面向开放科学问题的 Agent 持续探索与证据交付系统

## 赛题

题目类型二：开放探索赛题

## 一句话价值

把尚未结构化为标准 benchmark 的科学问题转成可持续探索环境，让 Agent
能够提出假设、执行行动、接收反馈、保留失败和反证，并输出可复现的发现信号。

## 作品做什么

ArenaForge 围绕统一的开放探索运行闭环组织科学问题、环境和证据：

```text
科学问题
  -> 环境协议与约束
  -> Agent 假设和行动
  -> 真实模拟器/公开数据/实验接口
  -> 结构化反馈
  -> 证据链、反证和 scoped conclusion
```

本次提交的 `Reference Arena #1：Quantum Optics` 固定三光子四维 GHZ
目标态、辅助光子预算和损耗协议。它是 ArenaForge 的第一个实例，用于展示
通用运行时如何承载真实物理探索。

## 当前已运行的最小探索

| 分支 | 结果 | 解释 |
|---|---:|---|
| canonical PyTheus | 74 条连接 | 性能参照，但超过资源预算 |
| sensitivity-guided | 49 条连接 | 74 次筛查、25 次连续删边后满足协议并推荐 |
| guided boundary action | 48 条连接 | 第 26 次删边的质量下降为 2.32%，触发边界 |

以上结果来自真实 PyTheus 运行、反馈引导搜索和独立损耗点验证。它体现
ArenaForge 的探索、判定和证据交付能力；结论范围由当前图结构、损耗代理、目标态
和预算定义。
