# ArenaForge GOAI 初赛作品摘要骨架

## 作品名称

ArenaForge：面向开放科学问题的 Agent 持续探索与证据交付系统

## 赛题

题目类型二：开放探索赛题

## 一句话价值

把尚未结构化为标准 benchmark 的科学问题转成可持续探索环境，让 Agent
能够提出假设、执行行动、接收反馈、保留失败和反证，并输出可复现的发现信号。

## 作品做什么

ArenaForge 的核心不是某一个科学领域，而是统一的开放探索运行闭环：

```text
科学问题
  -> 环境协议与约束
  -> Agent 假设和行动
  -> 真实模拟器/公开数据/实验接口
  -> 结构化反馈
  -> 证据链、反证和 scoped conclusion
```

本次提交的 `Reference Arena #1：Quantum Optics` 固定三光子四维 GHZ
目标态、辅助光子预算和损耗协议。它只是 ArenaForge 的第一个实例，
用于证明通用运行时可以承载真实物理探索。

## 当前已运行的最小探索

| 分支 | 结果 | 解释 |
|---|---:|---|
| canonical PyTheus | 74 条连接 | 性能参照，但超过资源预算 |
| threshold 0.150 | 49 条连接 | 质量下降 1.92%，满足协议并推荐 |
| threshold 0.200 | 48 条连接 | 质量下降 2.44%，因超过门槛被拒绝 |

以上结果来自真实 PyTheus 运行和统一损耗扫描。它证明的是
ArenaForge 的探索、判定和证据交付能力，不应被写成实验室实证或普遍物理规律。
