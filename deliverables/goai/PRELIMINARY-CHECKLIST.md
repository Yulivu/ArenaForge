# GOAI 初赛提交检查表

当前阶段：赛道三·题目类型二（开放探索赛题）

## 必交

- [ ] `problem-definition.pdf`，不超过 4 页
- [ ] 通过官方提交系统填写团队和报名信息
- [ ] 作品名称
- [ ] 选择 `题目类型二：开放探索赛题`
- [ ] 可访问的代码仓库
- [ ] 可访问的 Demo 链接
- [ ] 作品附件 ZIP
- [ ] ZIP 文件名为 `AI4R_OPEN_队伍名.zip`
- [ ] 单个 ZIP 不超过 1200 MB

## 问题定义文档必须回答

- [ ] 我们观察到的真实科学问题是什么？
- [ ] 为什么这个问题尚未被结构化为标准任务？
- [ ] 为什么 AI/Agent 适合介入？
- [ ] Agent 运行在什么探索环境中？
- [ ] Agent 能看到什么、改变什么、得到什么反馈？
- [ ] 哪些规则固定，哪些变量可以探索？
- [ ] 什么算发现：正结果、异常、反例、稳定负结果或问题修正？
- [ ] 平凡解、随机探索、无干预参照是什么？
- [ ] 第一次试跑如何进行？
- [ ] 主要风险和失败路径是什么？
- [ ] 数据、工具、依赖、运行和复现方式是什么？
- [ ] 后续开源计划和边界是什么？
- [ ] 团队成员、分工和既有成果是什么？

## 初赛不要求

- [ ] 不要求提交完整源代码仓库
- [ ] 不要求已经完成复赛级最小可运行环境
- [ ] 不要求已经完成完整探索日志
- [ ] 不要求已经给出正向科学发现

但文档必须把后续环境、日志、参照系和复现路径设计清楚。

## 重要限制

官方初赛模板明确要求独立完成，禁止使用 AI 作答。
ArenaForge 只能用于整理材料、检查结构、核对页数、检查引用和生成排版，
最终问题定义、判断和文字必须由参赛团队自行完成。
