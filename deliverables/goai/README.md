# GOAI 交付目录

这个目录只服务于 GOAI 赛道三·题目类型二。

## 已准备

- 官方手册和初赛模板的本地参考文件；
- 初赛上传检查清单；
- ArenaForge 作品摘要骨架及 Quantum Optics Reference Arena 说明；
- 官方问题定义的填写模板；
- 生成 `AI4R_OPEN_<队伍名>.zip` 的构建脚本，例如：
  `python scripts/build_goai_submission.py --team-name MAPLE`。

## 还需要参赛团队完成

官方模板明确要求参赛团队自行完成问题定义，且禁止使用 AI 作答。因此最终提交前必须由团队自行填写：

- 真实问题的背景与证据；
- 团队介绍；
- 最终问题定义 PDF；
- 代码仓库地址和 Demo 地址。

系统运行事实、候选结果、日志、复现命令和许可证说明已经可以由 ArenaForge 自动打包。
